# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-07-11

### Added
- Initial release of BioEnv: Biometric-Gated Local Secret Injector CLI.
- Core functionality for `set`, `get`, `list`, `delete`, `import`, and `run` commands.
- Secure secret storage using OS native keychains.
- Project-scoped secret isolation.
- Memory zeroization for sensitive data.
- Comprehensive documentation including `README.md`, `CONTRIBUTING.md`, `SECURITY.md`, and `LICENSE`.
- GitHub Actions for CI (linting, testing) and cross-platform binary releases.
